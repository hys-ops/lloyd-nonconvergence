Residual Sinkhorn case studies

MNIST handwriting

Keep the pixel grid; tighten the stopping bound

Early interpolation was 86× slower at one temperature. Keeping separable grid arithmetic and tightening the error bound cut a separate matched grid run from 73.61 to 66.62 ms.

What slowed down

Across 900 image pairs at regularization 0.12, the original separable-grid Sinkhorn run took 0.097 s versus 8.375 s for the early interpolation prototype. That prototype used an average of 344 sites instead of the 143 ink-bearing pixels per image. At regularization 0.02, the early prototype fell back to the original data and still took 4.565 s versus 0.373 s. These are historical matched timings including preparation.

What changed mathematically

The squared pixel distance splits into horizontal and vertical terms, so the Gibbs kernel factors into products of one-dimensional kernels. We retained those separable matrix products instead of interpolating extra sites. The stopping experiment then changed only the coefficient that turns a marginal residual into a full-plan error bound: it used the geometry of the shared Gibbs kernel rather than only a global row-count bound. With the same plan-TV budget, a tighter coefficient sometimes certified the iterate sooner.

Separate dense POT comparison

When both solvers materialized the full dense plans before computing costs, the earlier adapter was 1.55–2.15× as fast as stock POT across the three temperatures. That is a different benchmark, not the outcome of the grid-only change. The latest shared-check cleanup was paired against the preceding 0.3 candidate and saved a further 2.75% and 3.03% in the two dense MNIST suites.
